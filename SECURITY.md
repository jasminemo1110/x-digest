# Security Policy

## Supported version

The latest commit on `main` is the supported public-beta version. Older local copies may no longer match X's current page structure.

## Report a vulnerability

Once the public repository is available, please use GitHub's private vulnerability reporting feature if it is enabled. Otherwise, contact the maintainer through the public links on the [茉白 Jasmine GitHub profile](https://github.com/jasminemo1110) and ask for a private reporting channel before sharing details.

Please include the affected version or commit, Chrome version, impact, reproduction steps, and the smallest safe example needed to understand the issue.

Do **not** put API keys, cookies, login tokens, private posts, extension storage exports, or uncropped screenshots into a public Issue. Revoke a key immediately if it has been exposed.

## What belongs in a security report

Examples include unauthorized access to local records, accidental disclosure of post content or keys, unsafe rendering of AI output, permission escalation, or a way for page content to trigger an unintended privileged action.

Normal X DOM compatibility bugs, translation quality, and feature requests can be reported as regular Issues, provided the report contains no private data.
